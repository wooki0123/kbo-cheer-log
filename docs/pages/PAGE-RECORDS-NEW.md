# 새 기록 추가 페이지

경로: `/records/new`
인증: 필요

---

## 목적

새로운 직관 경기 기록 입력.

---

## 화면 구성

### 입력 폼

| 필드 | 타입 | 필수 |
|------|------|------|
| 경기 날짜 | 날짜 선택기 | 필수 |
| 홈팀 | 드롭다운 (KBO 10팀) | 필수 |
| 원정팀 | 드롭다운 (KBO 10팀) | 필수 |
| 결과 | 라디오 (승/패/무) | 필수 |
| 구장 | 드롭다운 (KBO 9개 구장) | 필수 |
| 날씨 | 드롭다운 (맑음/흐림/비/더움/추움) | 필수 |
| 별점 | 1~5점 선택 | 필수 |
| 메모 | 텍스트 영역 | 선택 |

- 저장 버튼
- 취소 버튼 → `/records`

---

## 유효성 검사

- 홈팀 ≠ 원정팀
- 날짜는 오늘 이전만 허용
- 별점은 1~5 정수

---

## 동작

1. 폼 제출 → `actions/records.ts` `createRecord` Server Action 호출
2. 성공 → `/records` 리다이렉트
3. 실패 → 오류 메시지 표시

---
