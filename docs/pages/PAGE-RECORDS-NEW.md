# 새 기록 추가 페이지

경로: `/records/new`
인증: 필요

---

## 목적

새로운 직관 경기 기록 입력.

---

## 화면 구성

### 입력 폼

| 필드 | 타입 | 필수 |
|------|------|------|
| 경기 날짜 | 날짜 선택기 | 필수 |
| 홈팀 | 드롭다운 (KBO 10팀) | 필수 |
| 원정팀 | 드롭다운 (KBO 10팀) | 필수 |
| 구장 | 드롭다운 (KBO 9개 구장) | 필수 |
| 날씨 | 드롭다운 (맑음/흐림/비/더움/추움) | 필수 |
| 우천취소 | 체크박스 (날씨 = '비' 일 때만 표시) | 조건부 |
| 결과 | 라디오 (승/패/무), 우천취소 시 비활성화/숨김 | 조건부 필수 |
| 별점 | 1~5점 선택 | 필수 |
| 메모 | 텍스트 영역 | 선택 |

### 경기 데이터 조회 (외부)

- 날짜 + 홈팀 + 원정팀 입력 후 **"경기 불러오기" 버튼** 표시
- 버튼 클릭 → `actions/naver.ts` `fetchGameData` 호출
- 조회 성공 시 하단에 읽기 전용으로 표시:
  - 이닝별 스코어 (1~9회, 연장 시 추가)
  - 홈/원정팀 안타 · 실책 · 볼넷
- 조회 실패 또는 데이터 없음 시: "경기 데이터를 찾을 수 없습니다" 메시지 (폼 저장은 가능)
- 조회된 데이터는 저장 시 DB에 함께 저장

- 저장 버튼
- 취소 버튼 → `/records`

---

## 우천취소 UI 규칙

- 날씨를 '비'로 선택하면 "우천취소" 체크박스가 나타남
- 우천취소 체크 시 결과(승/패/무) 필드를 숨기거나 비활성화
- 우천취소 체크 해제 시 결과 필드 다시 표시

---

## 유효성 검사

- 홈팀 ≠ 원정팀
- 날짜는 오늘 이전만 허용
- 별점은 1~5 정수
- 우천취소가 아닐 경우 결과 필수 입력
- 우천취소일 경우 결과는 NULL로 저장 (`is_cancelled = true`)

---

## 동작

1. 폼 제출 → `actions/records.ts` `createRecord` Server Action 호출
2. 성공 → `/records` 리다이렉트
3. 실패 → 오류 메시지 표시
