# 대시보드 페이지

경로: `/dashboard`
인증: 필요

---

## 목적

응원팀 기준 직관 통계를 한눈에 보여주는 메인 화면.

---

## 화면 구성

### ① 전체 요약 카드

- 총 직관 횟수
- 승 / 패 / 무 횟수
- 전체 승률
- 최근 5경기 전적 (W/L/D 뱃지 형태)

### ② 홈/원정 승률 비교

- 홈 경기 직관: N경기 / 승률 N%
- 원정 경기 직관: N경기 / 승률 N%
- (응원팀이 홈팀인 경기 vs 원정팀인 경기로 구분)

### ③ 구장별 방문 횟수

- 방문한 구장 목록 + 각 방문 횟수
- 미방문 구장은 표시하지 않음

### ④ 월별 직관 추이 차트

- 이번 연도 월별 직관 횟수 바 차트
- 라이브러리: Recharts

---

## 데이터 흐름

1. 페이지 로드 → `actions/profile.ts` `getProfile`로 응원팀 조회
2. `actions/records.ts` `getRecords`로 전체 기록 조회
3. 서버에서 통계 계산 후 컴포넌트에 전달

---

## 네비게이션

- 상단 헤더: 서비스 로고, "내 기록" 링크 → `/records`, 로그아웃
- "새 기록 추가" 버튼 → `/records/new`
