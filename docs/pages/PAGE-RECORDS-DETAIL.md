# 기록 상세/수정/삭제 페이지

경로: `/records/[id]`
인증: 필요

---

## 목적

특정 직관 기록의 상세 조회, 수정, 삭제.

---

## 화면 구성

### 조회 모드 (기본)

- 경기 날짜
- 홈팀 vs 원정팀
- 결과 뱃지 (승/패/무, 우천취소 시 '우천취소' 뱃지)
- 구장
- 날씨
- 별점
- 메모
- 경기 데이터 (조회된 경우): 이닝별 스코어 테이블, 안타/실책/볼넷
- 수정 버튼 → 편집 모드 전환
- 삭제 버튼 → 확인 다이얼로그 후 삭제

### 편집 모드

- 새 기록 추가 폼과 동일한 필드
- 저장 버튼
- 취소 버튼 → 조회 모드 복귀

---

## 동작

**수정**
1. 편집 모드에서 저장 → `actions/records.ts` `updateRecord` 호출
2. 성공 → 조회 모드로 복귀 (데이터 갱신)

**삭제**
1. 삭제 버튼 클릭 → 확인 다이얼로그 표시
2. 확인 → `actions/records.ts` `deleteRecord` 호출
3. 성공 → `/records` 리다이렉트

**권한**
- 본인 기록만 접근 가능. 타인 기록 접근 시 404 처리.
