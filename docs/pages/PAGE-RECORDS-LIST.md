# 직관 기록 목록 페이지

경로: `/records`
인증: 필요

---

## 목적

내가 기록한 모든 직관 이력을 목록으로 확인.

---

## 화면 구성

- 기록 카드 목록 (최신순 정렬)
  - 각 카드: 날짜, 홈팀 vs 원정팀, 결과 뱃지(승/패/무), 구장, 별점
- "새 기록 추가" 버튼 → `/records/new`
- 기록 없을 때: 빈 상태 안내 + 추가 버튼

---

## 데이터 흐름

1. 페이지 로드 → `actions/records.ts` `getRecords` 호출
2. 전체 기록 목록 반환 (최신순)
3. 각 카드 클릭 → `/records/[id]`

---
